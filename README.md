# Digital-image-processing

## Project Overview

This repository contains signal processing projects implemented in Jupyter Notebook. The work covers signal creation, manipulation, analysis, and various filtering techniques including spectrograms and custom filter implementations.

## Description

Collection of digital signal processing (DSP) exercises demonstrating fundamental concepts in audio and signal analysis. Projects include signal generation, time-frequency analysis, and filter design with practical applications to audio signals.

## Project 1: Signal Analysis and Audio Filtering

**Topics:**
- Signal creation and manipulation
- Signal analysis and visualization
- Spectrograms (time-frequency representation)
- Audio signal filtering
- Digital filter application to real audio data


## Project 2: Custom Filter Design and Implementation

**Topics:**
- IIR (Infinite Impulse Response) filter design
- FIR (Finite Impulse Response) filter design
- Filter frequency response analysis
- Signal processing with custom filters
- Comparing filter characteristics


## Tools & Technologies

- **Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** NumPy, SciPy, Matplotlib, librosa
